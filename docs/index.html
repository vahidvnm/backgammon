AI Backgammon

Privacy Policy — Effective September 24, 2026

AI Backgammon is a completely offline board game. It works without an account, advertising identifier, analytics SDK, or network connection.

Data collection

AI Backgammon does not collect, transmit, sell, or share personal data. It contains no advertising, analytics, tracking, account creation, crash-reporting SDK, or in-app purchases.

On-device data

Game settings, appearance choices, and the current match position and score are stored only on the player's device so a match can be restored. This information is never sent to the developer or a third party.

Permissions

The app may use vibration for optional haptic feedback. It does not request internet, location, contacts, camera, microphone, storage, or notification permissions.

Children

The app does not knowingly collect information from children because it collects no personal information.

Contact

For support or privacy questions, use the GitHub Issues page.
