# Google Play Data Safety answers

Use this as a submission worksheet; verify it again whenever dependencies or features change.

- Does the app collect or share required user data types? **No**
- Is all user data encrypted in transit? **Not applicable — no data is transmitted**
- Can users request data deletion? **Not applicable — no developer-held data; local data is removed by clearing app storage or uninstalling**
- Does the app contain ads? **No**
- Account creation: **No**
- Analytics: **No**
- Advertising or marketing: **No**
- Fraud prevention/security telemetry: **No**
- Personalization based on collected data: **No**
- Approximate or precise location: **Not collected**
- Device identifiers: **Not collected**
- Crash logs/diagnostics sent off device: **Not collected**
- Financial information: **Not collected**
- Photos, audio, contacts, files, messages and health data: **Not collected**

The only declared Android permission is `android.permission.VIBRATE`, used for optional local haptic feedback.
